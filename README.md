## Sobre o projeto

Site single-page criado para apresentar os serviços da THERA STUDIO, com hero animado, showcase de trabalhos criados com IA generativa, galeria de portfólio, seção de serviços e contato direto via WhatsApp.

## Stack & Ferramentas

O projeto foi construído combinando IA generativa de código e design com refinamento manual:

- **Kimi** — geração inicial da estrutura total do site (React + TanStack Start)
- **Lovable** — apoio na geração, ajuste de código e implementação de novos recursos.
- **Claude (Anthropic)** — Análise técnica
- **HTML, CSS e JavaScript** — mais de 2.000 linhas de código no total
- **Base64** — todas as imagens do site são embutidas diretamente no HTML (`data:` URI), tornando o projeto um **arquivo único e portátil**, sem dependências externas de storage/CDN
- **GitHub Pages** — hospedagem estática do site
